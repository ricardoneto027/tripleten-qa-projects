# 🎓 TripleTen QA Engineer Bootcamp — Projetos

Repositório com todos os projetos práticos realizados durante o bootcamp de **QA Engineer** da TripleTen.
Cada sprint tem a sua pasta com test cases, bug reports, scripts de automação e artefactos relevantes.

📌 Sobre mim e o meu percurso: consulta o [README do meu perfil](https://github.com/ricardoneto027).

## 🧠 Skills desenvolvidas

- **Test analysis & design**: classes de equivalência, valores-limite, checklists de requisitos
- **Testes manuais**: regressão, funcionais, smoke, aceitação (UAT)
- **Testes de API**: REST, Postman, rastreabilidade de bugs
- **Testes mobile**: emulador Android Studio
- **Linux & SQL**: análise de logs via SSH, consultas PostgreSQL
- **Automação de testes**: Python, Pytest, Selenium WebDriver
- **Bug reporting**: Jira, com rastreabilidade completa e priorização

- **Test management**: Google Sheets, Markdown
