# Sprint 3 — Testes Funcionais Web: Urban Routes

Testes funcionais completos sobre a funcionalidade de **partilha de carros**
do Urban Routes, cobrindo layout, pagamento, reserva e locação de veículos.

## 📝 Conclusões

A aplicação Urban Routes apresenta uma interface simples e intuitiva, permitindo realizar reservas de forma relativamente rápida. No entanto, foram identificados problemas que afetam diretamente a experiência do utilizador, especialmente em funcionalidades críticas como validação de dados, comportamento de botões e fluxo de reserva — sendo o mais crítico a impossibilidade de cancelar uma corrida.

Apesar de apresentar uma boa base funcional e uma interface clara, os problemas identificados afetam funcionalidades essenciais do sistema.

**Na sua forma atual, a aplicação não está pronta para disponibilização aos utilizadores finais.** Recomenda-se a correção dos bugs identificados, em particular os relacionados com lógica de negócio e validação, antes do lançamento. Após essas correções, o produto tem potencial para oferecer uma boa experiência ao utilizador.
